Dev Scout

The agent screens. HR decides.

Dev Scout reads each developer CV, analyzes the candidate's GitHub, scores them against the criteria HR set for the role, and ranks everyone in a live dashboard with evidence and tailored interview questions.

For HR

Create your own role

Every role has its own weighted criteria. New applications for that role are scored with exactly those criteria, so the ranking reflects what you care about.

  1. 1 Open Roles in the dashboard and click New role.
  2. 2 Pick a template to start from.
  3. 3 Adjust the weights. A live preview shows each criterion's share of the score.
  4. 4 Save. The next applications are scored with your criteria.
Under the hood

How the agent works

One n8n workflow runs every application from intake to HR notification.

  1. Form or EmailA candidate applies on the web form or emails a PDF CV.
  2. Match roleThe application is matched to an open role and its criteria.
  3. Read CVClaudeTurns the PDF into structured data, including hidden links.
  4. Analyze GitHubGitHub APIMeasures consistency, variety, collaboration and best repos, with no AI.
  5. ScoreClaude + mathClaude rates each criterion with evidence; code computes the final score.
  6. SaveOne row per candidate and role, updated if they apply again.
  7. HR email + DashboardHR gets an alert and the candidate appears in the live ranking.
Transparent by design

How scoring works

Claude scores each criterion from 0 to 10 and writes one sentence of evidence. The final 0 to 100 score is calculated in code from HR's weights. The AI never invents the final number.

The formula

score = round( sum(score × weight) / sum(10 × weight) × 100 )

Fit labels

Strong fit70 and above
Possible fit50 to 69
Weak fitBelow 50

Privacy

Only what hiring needs

Dev Scout stores professional information and nothing that could bias the ranking.

  • Stored: name, email, phone, links and professional information only.
  • Never stored: birth date, national ID, home address, photo. Leaving out the birth date also keeps age out of the ranking.
  • The form requires consent. Email applicants are told in the auto-reply that their data is stored and how to ask for removal.
  • The dashboard requires an access key. Keys and credentials are not in the repo.
Self-host

Run your own copy

About 20 minutes with an n8n account, a Gmail account and an Anthropic API key or n8n AI credits.

  1. Create the jobs and candidates Data Tables in n8n.
  2. Import the two workflows and connect Gmail and Claude.
  3. Set a long random access key and publish both workflows.
